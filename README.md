# Avito Bot Detection

Решение тестового задания для отбора на Avito Bootcamp. Задача — по событиям
внутри суточного окна оценить вероятность того, что `cookie_id` относится к
автоматизированному сервису сбора данных.

Основная метрика — **Precision при Recall ≥ 70%**. Финальный результат на
проверяющей системе: **0.80397**.

## Подход

Я сначала фильтрую события по индивидуальным границам наблюдения, после чего
строю признаки активности, временных интервалов, сессий, поиска, воронки
действий, User-Agent и последовательностей событий.

В финальном решении я объединяю процентильные ранги нескольких моделей HGB и
CatBoost. Один из компонентов CatBoost обучается с временным затуханием, чтобы
сильнее учитывать свежие наблюдения. Все random seed зафиксированы.

Для проверки качества я использую forward-validation: модель обучается только
на прошлых датах и проверяется на следующих временных отрезках.

| Модель | Средний P@R≥70% |
|---|---:|
| Простой HGB baseline | 0.2726 |
| Сильный reference | 0.7635 |
| Финальный ансамбль | **0.7683** |

## Данные

Мне не удалось разместить `data/events.csv` в GitHub-репозитории из-за размера
файла. Поэтому вместе со ссылкой на репозиторий я прикладываю архив с полным
набором файлов решения, включая `events.csv`.

Для локального запуска нужно поместить файл событий в папку `data`:

```text
data/events.csv
```

Ноутбук также поддерживает сжатый вариант `data/events.csv.gz`. При запуске на
Kaggle он автоматически использует путь к подключённому датасету.

## Запуск

Рекомендуемая версия — **Python 3.12**.

```bash
python -m pip install -r requirements.txt
```

После установки зависимостей нужно открыть
`avito_bot_detection_solution.ipynb` и выполнить **Restart & Run All**. Ноутбук
повторит валидацию, обучит финальный ансамбль и создаст `submission.csv`.

Решение не использует внешние данные, API, большие языковые модели или ручную
разметку тестовой выборки.
